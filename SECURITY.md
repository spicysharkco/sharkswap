# Security policy

## Reporting a vulnerability

Please report a vulnerability privately, through GitHub private vulnerability
reporting: <https://github.com/spicysharkco/sharkswap/security/advisories/new>.
Do not open a public issue for it. A report that says what you did, what you
expected and what happened is enough.

## Supported versions

While the project is 0.x, only the latest release gets fixes.
